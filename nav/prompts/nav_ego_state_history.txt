- Map: +X = East (right), +Y = South (down), -X = West (left), -Y = North (up)
- Headings: θ=0°→West, θ=90°→North, θ=180°→East, θ=270°→South

## CURRENT STATE
- Position: ({curr_x}, {curr_y})
- Target: ({target_x}, {target_y})
- Distance: {distance} px
- Heading: {theta}°
- Allowed actions: {allowed_actions}

## MOVEMENT HISTORY
{history}

## ACTIONS & POSITION CHANGES (each move = 34 px)

**Turning** (changes θ only, position unchanged):
- turn right: θ = (θ + 90) mod 360
- turn left: θ = (θ - 90) mod 360

**Moving** (changes position only, θ unchanged):

When θ=0° (West):  forward→(-34,0)  
When θ=90° (North): forward→(0,-34) 
When θ=180° (East): forward→(+34,0)  
When θ=270° (South): forward→(0,+34)  

**Stop**: Use when distance ≤ 20 px

## DECISION PRIORITY
1. **CHECK HISTORY** - Review recent movements. Avoid repeating failed actions or getting stuck in loops.
2. **AVOID OBSTACLES FIRST** - Check egocentric view. Never choose an action that collides with obstacles (walls, shelves, robots). Agent is human-sized.
3. **REDUCE DISTANCE** - Pick the action that moves closer to target without collision. Use your heading and target position to determine if you need to turn.
4. **MAKE PROGRESS** - If distance hasn't decreased in recent history, consider a different approach.
5. **STOP** - When within 20 px of target.
